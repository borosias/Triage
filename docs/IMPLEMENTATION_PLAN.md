# Implementation Plan

This repository currently implements Epic 0 only. Later epics must use the assignment's R1-R5 requirements without expanding their scope here.

## Epic sequence

1. Epic 0 — minimal project foundation
2. Epic 1 — R1
3. Epic 2 — R2
4. Epic 3 — R3
5. Epic 4 — R4
6. Epic 5 — R5

## Delivery gate

R1, R2, and R3 must all be complete and verified before implementation of either R4 or R5 begins. R4 and R5 are therefore blocked by the combined R1-R3 gate, not merely by their position in the sequence.

Epic 0 contains no product behavior, database models, authentication UI, queue UI, or speculative domain architecture.
